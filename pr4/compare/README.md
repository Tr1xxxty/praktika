# Порівняння
Запуск із папки роботи: `python compare/run.py` після заповнення `.env`.
Набір містить 7 звернень; ПР4 додатково містить 2 діалоги по 3 репліки.
Скрипт записує відповіді, час, usage, помилки та зведення. Для ПР4 перевіряє схему навіть у базових режимах, але не приховує невалідні відповіді в експериментальному файлі.
Порівняння потребує реального API-ключа. У комплекті немає вигаданих відповідей чи метрик.
У `results.json` заповніть `review`: factual_error, correct_topic, remembers_order, error_type.
Синтаксичні помилки ловить схема; вигаданий номер — перевірка наявності в репліках клієнта; факти й дотримання ролі потребують ручного аналізу.
