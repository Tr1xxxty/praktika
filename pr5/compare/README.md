# Порівняння
`python compare/run.py` з папки pr5 запускає 14 запитів через E5 і BM25, потім змінює лише CHUNK_SIZE на +300 та повторює дослід. Записує ранги, оцінки, час, hit@1/hit@3 і пробний поріг. Внутрішній документ — негативний тест доступу; його не включено в знаменник hit@k. Публічний пошук завжди обмежує audience=клієнти.
