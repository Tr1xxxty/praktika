# Статус перевірок

Дата: 31.10.2026. Середовище перевірки: Linux, Python 3.12, CPU. Версії основних бібліотек — TESTED_VERSIONS.txt. На Windows інструкції підготовлено, але виконання на Windows не перевірялося.

## Виконано
- 20 автоматичних тестів пройдено: HTTP-помилки, порожній ввід, декодування зображень, серіалізація детекцій, повтори API, сувора схема, вигаданий номер замовлення, бюджет історії, ізоляція сесій, збереження індексу, фільтри до top-k, відсутній індекс та політика доступу.
- ПР1: справжні запити Open-Meteo для Kyiv, Bratislava, London, неіснуючого міста й порожнього рядка. Відповіді — pr1/checks.json.
- ПР2: справжній YOLOv8n, 5 зображень, 3 пороги. Дані, рамки та час — pr2/eval/results.json; аналіз — conclusions.md. Рамки базового порога переглянуто.
- ПР5: справжній intfloat/multilingual-e5-small, 16 документів, базовий індекс із 127 фрагментів по 384 виміри; 14 запитів, два методи, два розміри. Метрики та висновки — pr5/compare/.
- Усі 5 серверів запускаються через uvicorn, віддають головну сторінку та OpenAPI. ПР5 завантажує індекс і виконує keyword-пошук. Результати — server-checks.json.
- JavaScript усіх 5 сторінок пройшов node --check.

## Потребує вашого запуску
- ПР3 та ПР4: реальні виклики Gemini і порівняння якості не виконано, тому що API-ключ не надано. Немає вигаданих відповідей чи заповнених заднім числом експериментів. Заповніть .env та виконайте python compare/run.py у кожній папці. Після цього перевірте факти вручну за context.md та доповніть висновки.
- Повна візуальна перевірка інтерфейсів у браузері не виконана: завантаження тестового Chromium завершилося помилкою архіву. Перевірені HTTP-маршрути й синтаксис JS; це не еквівалент браузерного тесту.

## Межі рішення
ПР4 — локальний однопроцесний навчальний сервер з історією у пам’яті. Схема перевіряє форму та згаданий номер, але не доводить правдивість усіх фактів. ПР5 використовує малий набір для калібрування порога, а не незалежний тест якості. ПР2 містить початковий набір із 5 зображень, а не репрезентативний бенчмарк.

Архів готовий для додавання у Git. Для повного виконання емпіричної частини ПР3–ПР4 потрібні описані вище реальні прогони з вашим ключем.
